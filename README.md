# تَدَبُّر (Tadapor)

تطبيق إسلامي شامل لمواقيت الصلاة، الأذان، الأذكار، القرآن الكريم، وتحديد القبلة.

## الميزات الحالية

- ✅ مواقيت الصلاة حسب طرق حساب أهل السنة والجماعة
- ✅ اختيار المذهب (شافعي / حنفي)
- ✅ أذكار من مصادر سنية موثوقة (حصن المسلم، النووي، البخاري، مسلم...)
- ✅ عداد للأذكار
- ✅ بوصلة القبلة
- ✅ هيكل القرآن (جاهز للربط مع نص وصوت)
- ✅ هوية إسلامية (ألوان أخضر/ذهبي + خط أميري)
- ✅ **صوت الأذان + جدولة الإشعارات تلقائياً** (لـ 7 أيام)
- ✅ إشعارات كاملة الشاشة (Full Screen Intent)
- ✅ تجربة الأذان والإشعار من الإعدادات

## صوت الأذان وجدولة الإشعارات

عند تحديد الموقع يتم جدولة إشعارات الصلوات الخمس (الفجر، الظهر، العصر، المغرب، العشاء) تلقائياً لمدة 7 أيام.

من شاشة المواقيت ← أيقونة الإعدادات:
- تفعيل / إيقاف تنبيهات الأذان
- تجربة صوت الأذان
- تجربة الإشعار
- إعادة جدولة التنبيهات

### تثبيت ملف الصوت (مهم)

1. ضع الملف `adhan.mp3` في:
   ```
   assets/audio/adhan.mp3
   ```

2. **لأندرويد** (لكي يصدر الصوت من الإشعار نفسه):
   انسخ نفس الملف إلى:
   ```
   android/app/src/main/res/raw/adhan.mp3
   ```
   (اسم الملف بأحرف صغيرة فقط)

3. نفّذ:
   ```bash
   flutter clean
   flutter pub get
   flutter run
   ```

راجع الملف: `assets/audio/README_AUDIO.txt`

## المصادر المعتمدة (سنية فقط)

### الأذكار
- حصن المسلم - سعيد بن علي بن وهف القحطاني
- الأذكار للنووي
- صحيح البخاري ومسلم
- رياض الصالحين
- الكلم الطيب لابن تيمية

### طرق حساب المواقيت
- رابطة العالم الإسلامي
- الهيئة المصرية العامة للمساحة
- جامعة أم القرى
- جامعة العلوم الإسلامية كراتشي
- ISNA
- وغيرها من الطرق السنية المعتمدة

**تم تجنب أي مصدر شيعي أو مشكوك فيه.**

## التشغيل المحلي

```bash
flutter pub get
flutter run
```

## التشغيل عبر GitHub Codespaces

المستودع: https://github.com/TEaG3/Tadapor

1. ارفع ملفات المشروع إلى المستودع.
2. من صفحة المستودع: **Code → Codespaces → Create codespace on main**
3. بعد اكتمال التحميل:

```bash
flutter pub get
flutter run -d web-server --web-port=8080 --web-hostname=0.0.0.0
```

التفاصيل الكاملة في ملف [CODESPACES.md](CODESPACES.md)

## ما يحتاج إكمال لاحقاً

1. **نص القرآن الكامل + الصوت**: everyayah.com أو ملفات محلية.
2. **ويدجت الشاشة الرئيسية**: Android App Widget + iOS WidgetKit.
3. **خطوط**: Amiri و UthmanicHafs في `assets/fonts/`.
4. اختبار الإشعارات على جهاز حقيقي (Exact Alarms + Full Screen Intent).
